## 🚀 Sobre mim

Sou **Gustavo Marques**, Software Engineer & Front-End Specialist com **5+ anos de experiência** construindo produtos digitais escaláveis e de alta conversão para os setores de **Fintech, SaaS e Gateways de Pagamento**.

💡 **Meu diferencial é a ponte entre Design e Engenharia (UX/UI-Driven):** com proficiência em **Figma**, colaboro diretamente com times de produto para transformar requisitos complexos em código limpo, de alta performance e acessível (WCAG).

- 🔭 **Atualmente:** Desenvolvendo aplicações de alta complexidade em React/Next.js focadas em experiência do usuário e conversão.
- 💬 **Pergunte-me sobre:** React, Next.js, TypeScript, Design Systems, Otimização de Performance (Web Vitals) e Arquitetura Frontend.
- ✍️ **Escrevo artigos técnicos sobre:** WebSockets, Supabase, Git/Conventional Commits e Busca Digital no meu [Portfólio](https://portfolio-gms.vercel.app/).

## 💡 Principais Experiências Adquiridas

- 🏗 **Arquitetura Frontend do Zero:** Definição de estrutura de arquivos, padrões de projeto e bibliotecas de componentes modulares/escaláveis em ecossistemas React/TypeScript.
- 🎨 **Desenvolvimento de Checkout Builder:** Criação de interfaces personalizáveis do tipo *drag-and-drop*, focadas em otimização de conversão em ecossistemas de pagamento.
- ⚡ **Sistemas em Tempo Real:** Integração de WebSockets e APIs de alta vazão para sistemas de automação de mensagens e atualização de dados ao vivo.
- ♿ **Acessibilidade & Design Systems:** Implementação de padrões **WCAG** (Acessibilidade Web), componentes reutilizáveis com *design tokens* e layouts responsivos mobile-first.
- 🔒 **Integração de APIs & Conformidade:** Consumo eficiente de APIs REST e GraphQL, garantindo interrupção zero no fluxo de dados e boas práticas de segurança de produtos financeiros.
- 📊 **Qualidade de Código & Performance:** Testes unitários/integração (Jest, React Testing Library), refatorações estratégicas e otimização de métricas Web Vitals/Lighthouse.
